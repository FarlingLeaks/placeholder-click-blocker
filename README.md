# Placeholder Click Blocker

Stops accidental clicks on bank placeholders.

- Left-clicking a placeholder in the bank does nothing. Its options (Release, Examine) are still in the right-click menu.
- **Hide right-click options**: removes the placeholder's options from the right-click menu as well.
- **Allow clicks while holding Shift** (on by default): hold Shift to use placeholders normally, e.g. to release one.
